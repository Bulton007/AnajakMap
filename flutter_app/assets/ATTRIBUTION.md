# Bundled assets

- `images/angkor.jpg`: temple-complex photograph from [Pexels photo 15890461](https://www.pexels.com/photo/angkor-wat-temple-complex-in-cambodia-15890461/), retrieved 4 October 2026. Used as destination imagery under the [Pexels license](https://www.pexels.com/license/). It is not live place/availability evidence.
- `fonts/NotoSansKhmer.ttf`: Noto Sans Khmer variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanskhmer). SIL Open Font License text is bundled alongside it.
- Material icons are supplied by the Flutter SDK.
- `fonts/CormorantGaramond.ttf`: Cormorant Garamond variable font from the official Google Fonts repository (`ofl/cormorantgaramond`), retrieved 6 October 2026. SIL Open Font License is bundled as `CormorantGaramond-OFL.txt`. English auth headings use it; Khmer uses the bundled Noto Sans Khmer.

No remote image/font request is required at app runtime.
